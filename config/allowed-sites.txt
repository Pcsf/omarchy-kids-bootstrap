# Browser allowlist for the child. Everything else is blocked by policy.
# One URL pattern per line, Chromium URLBlocklist/URLAllowlist syntax:
#   example.com        matches example.com and every subdomain
#   .example.com       matches example.com only, no subdomains
#   example.com/path   matches that path prefix
# '#' starts a comment. Changes apply after the browser-policy module re-runs.
#
# The policy blocks page and frame navigations, not the scripts and images a
# page loads. A site breaks where it sends the browser to another domain: a
# sign-in provider, an embedded video, a robot check. Find that domain in the
# address bar of the "blocked" page or in chrome://policy/logs, add it below
# and re-run ./bootstrap.sh --only browser-policy.
